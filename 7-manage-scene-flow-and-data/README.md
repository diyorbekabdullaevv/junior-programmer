## About

Manage Scene Flow and Data is the seventh section of Unity Technologies' official Junior Programmer learning pathway. It focuses on managing scenes, storing data, using version control, and applying Object-Oriented Programming principles in Unity projects.

The section introduced Git and GitHub for version control, including repositories, commits, pushing, pulling, merging, and resolving merge conflicts.

I also learned about scene management using SceneManager, UI-based scene navigation, and application flow. Data persistence was covered using DontDestroyOnLoad, static members, and the Singleton pattern.

The section also introduced saving and loading data between application sessions using JSON serialization, JsonUtility, and file handling with System.IO.

Finally, I learned the four main OOP principles: abstraction, encapsulation, inheritance, and polymorphism.
