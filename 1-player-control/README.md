## About

Player Control is the first section of Unity Technologies' official Junior Programmer learning pathway, designed to introduce programming fundamentals through practical Unity game development.

Throughout the section, I built a car-based gameplay project where the player controls a car moving side-to-side on a floating road while interacting with obstacles. I learned how to create and manage Unity projects, work with GameObjects and components, use physics, and write basic C# scripts to control gameplay behavior.

This section gave me my first practical experience with C# scripting in Unity and helped me build a strong foundation for the next stages of the Junior Programmer pathway.

## What I Learned

- Unity project creation and management
- Unity Editor workflow
- Scene View navigation
- GameObjects and Components
- Transform, Mesh Filter, and Mesh Renderer
- Materials and object appearance
- Colliders and Rigidbody
- Physics and Physics Materials
- Creating and attaching C# scripts
- `MonoBehaviour`
- `Start()` and `Update()`
- Transform and rotation
- C# data types and variables
- Public variables and the Unity Inspector
- C# naming conventions
- Trigger interactions with `OnTriggerEnter()`
