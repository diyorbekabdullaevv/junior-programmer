## About

Basic Gameplay is the second section of Unity Technologies' official Junior Programmer learning pathway, designed to introduce more programming and gameplay concepts through a practical Unity project.

In this section, I built a top-down game where the player throws food at hungry animals running toward them. The goal is to hit the animals with projectiles before they can run past the player.

Throughout the section, I worked with C# logic and Unity gameplay systems to create projectiles, spawn objects, detect collisions, and control the flow of the game.

This section helped me move beyond basic scripting and start building more complete gameplay systems.
