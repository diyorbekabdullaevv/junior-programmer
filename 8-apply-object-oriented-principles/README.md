## About

Apply Object-Oriented Principles is the eighth and final section of Unity Technologies' official Junior Programmer learning pathway. It focuses on applying Object-Oriented Programming principles to improve code structure, readability, maintainability, and performance.

The section provided a deeper understanding of the four main pillars of OOP: abstraction, encapsulation, inheritance, and polymorphism. It also introduced code refactoring as a way to improve existing code without changing its external functionality.

I learned how abstraction can simplify complex functionality, reduce duplicate code, and make code more reusable. Encapsulation was used to protect data and control how values are accessed and changed through access modifiers, properties, getters, setters, and backing fields.

The section also introduced Unity's Profiler for identifying performance bottlenecks and optimizing inefficient code. Finally, it covered career preparation, including Unity certifications, portfolio and resume development, job research, and interview preparation.
