## About

Sound and Effects is the third section of Unity Technologies' official Junior Programmer learning pathway, focused on adding audio and visual feedback to gameplay.

In this section, I built a fast-paced endless side-scrolling runner where the player must time jumps to avoid incoming obstacles. I learned how to create a jumping mechanic, add background music and sound effects, and create an endlessly repeating environment for a side-scrolling game.

I also learned how visual particle effects can improve gameplay feedback and make interactions such as collisions, splatters, and explosions more satisfying.

This section helped me understand how audio, animation, visual effects, and gameplay systems can work together to create a more engaging game experience.
